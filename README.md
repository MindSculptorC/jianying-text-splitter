# 剪映文本切段助手

把剪映时间轴上的文本当作片段标签：按每条文本自己的起止时间切出视频、移除可编辑文本，再按标签归档到文件夹。适合整理 B-roll 素材。

**当前为 Mac 版，需要自行安装剪映专业版和 Python 3.9+，不是免环境安装包。**

[下载 Mac 版](https://github.com/MindSculptorC/jianying-text-splitter/releases/latest) · [反馈问题](https://github.com/MindSculptorC/jianying-text-splitter/issues)

## 功能

- 按每条文本的开始时间和持续时间切段，原草稿保留。
- 建立去文字副本，交给剪映渲染整片，再通过 AVFoundation 切分。
- **精准匹配**完整同名目录；**模糊匹配**常见近义词和相似名称，候选歧义时提示指定。
- 自由选择总目录、全部直接输出到同一目录，或每段单独指定其他位置。
- **增量更新**校验并跳过未变片段，只补导新增或修改片段；画面一致时复用历史无文本母版。
- 改动片段另存新版，不覆盖旧文件。删除文本标记不会删除已归档视频。
- 全程本机处理，无云端上传、无 API Key、无 pip 第三方依赖。

## 下载安装

1. 从 Releases 下载 `jianying-text-splitter-v2.0.1-macos-universal.zip`，不要误下自动生成的 Source code 包。
2. 解压，将 **剪映文本切段助手.app** 放入「应用程序」。
3. 安装并正常运行过剪映专业版。默认路径 `/Applications/VideoFusion-macOS.app`；不同位置可通过助手底部的「剪映位置」选择。
4. 安装 [Python 3 for macOS](https://www.python.org/downloads/macos/)，至少 3.9。助手会检测 python.org、Homebrew 和已安装开发工具中的 Python；自定义路径点「Python 位置」。
5. 打开助手，在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许助手控制剪映。密码只输入在 macOS 系统弹窗里。

发布包使用本地 ad-hoc 签名，**尚未使用 Apple Developer ID 签名或公证**。首次运行可能出现来源提示；确认下载来源后，按 macOS 提示允许这个应用。不需要关闭系统整体安全保护。更新后权限失效时，可移除旧辅助功能条目并重新添加新版。

应用包含 Apple 芯片（arm64）与 Intel（x86_64）两个架构；最低构建目标 macOS 12，实际验证环境 macOS 15.1 / Apple Silicon。Intel 和其他系统版本尚未实机验证；没有 Windows 版。

## 使用步骤

1. 在剪映中保存草稿，文本标签写成类别，例如「单张」「折线图」「关键词」。
2. 在助手选择草稿与输出总目录，再选匹配模式和归档方式。默认开启增量更新。
3. 点击 **读取时间轴**，核对时间、位置与更新状态。点击某段目标位置可指定任意目录，「恢复匹配」撤销该段手动位置。
4. 点击 **导出 N 段**。需要新母版时会正常关闭剪映、注册独立副本，再打开剪映渲染；此时暂时不要操作鼠标键盘。
5. 画面未变且历史母版有效时直接补切。全部片段未变时只校验，无需控制剪映。

分类目录示例：

```text
我的素材库/
├── 图片素材/
│   ├── 单张/
│   ├── 多张/
│   └── 文献资料/
├── 数据文本/
│   └── 关键词/
└── 可视化图表/
    └── 折线图/
```

「匹配分类子文件夹」递归查找已有子目录；「全部放入总文件夹」支持空目录。系统目录选择器可以新建文件夹。

精准模式要求完整同名。模糊模式先找同名，再尝试「参考文献→文献资料」「关键字→关键词」「趋势图→折线图」等。它是本地规则，不是通用大模型语义理解；多个相近候选会阻止导出。新用户不会继承作者的个人文件夹和标签映射。

## 增量与恢复

保留总目录下隐藏的 `.剪映切段任务`，里面包含任务计划、母版和完成清单。

| 状态 | 含义 |
| --- | --- |
| 已导出 · 跳过 | 片段与历史一致，视频 SHA-256 校验通过 |
| 新增 · 待导出 | 新文本标记 |
| 有变化 · 待更新 | 时间、标签、目标位置、画面或输出文件改变 |

对视频轨、音频、效果、原素材或其他非文本信息变化采取保守判断：整份草稿片段重新生成。换总目录后在新位置独立建立记录，不搬走旧视频。

**v1 没有素材指纹，首次升级需要建立 v2 记录；旧视频保留。**

中断时点 **继续切分 / 校验**；冻结计划、母版或已完成文件被改动时会停止，也可以重新读取草稿建立新的增量任务。

自动控制不兼容当前剪映界面时，可手动打开生成的 `切段助手_…` 副本，从 00:00 导出完整无文本视频，再点 **选择已导出的无文本整片**。不要选择原草稿的带文本整片。

## 使用边界

- 去除的是剪映可编辑文本。**烧录在源视频里的字幕、Logo、水印会保留。**
- 剪映编码、内部接口和界面可能随版本改变，不保证所有版本兼容。早期完整流程验证版本信息为 `11.3.13183 / 11.4.7-beta1`。
- 适配器调用使用者本机安装的剪映组件。仓库与发布包不包含剪映引擎、第三方素材、私人草稿或媒体。
- 本工具是独立辅助工具，不是剪映官方产品。公开反馈问题前请去掉私人路径和草稿信息。

## 从源码构建

需要 macOS、Apple Command Line Tools、Python 3.9+。构建不要求安装剪映；实际编解码与渲染时需要。

```sh
xcode-select --install
bash package.sh
```

产物位于 `dist/`：应用、ZIP、使用说明、`SHA256SUMS.txt`。下载后在对应目录执行 `shasum -a 256 -c SHA256SUMS.txt` 可核对文件。

```sh
python3 -m unittest discover -s tests -v
python3 -m unittest test_register -v
python3 native/test_media_export.py
# 可选：已安装兼容剪映时进行合成编解码测试
python3 native/test_codec.py
```

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `core.py` | 时间轴读取与无文本副本 |
| `iteration.py` | 匹配、指纹、增量校验与母版复用 |
| `workflow.py` | 冻结任务、切分和恢复 |
| `register.py` | 注册副本、保护和备份草稿索引 |
| `native/` | Mac 界面、剪映控制、视频处理和编解码源码 |
| `ui/index.html` | 离线界面 |
| `tests/` | 不含个人素材的合成测试 |

接口研究参考：[jy-draftc-mac](https://github.com/wenshui330/jy-draftc/tree/main/jy-draftc-mac) 的 `EncryptUtils` 声明。适配器独立实现动态查找、JSON 检查、独占写入和回环校验；不分发剪映动态库。
